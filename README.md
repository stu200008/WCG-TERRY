# WNACG plugin

A Kinoko v3 plugin for WNACG, with update, doujinshi, single-volume, and weekly ranking tabs, search, in-app page reading, and the site's direct ZIP download URI.

Each WNACG album is one book with one chapter; all image pages are loaded inside that chapter. On the book page, the download icon opens the official archive URI when WNACG provides one.
